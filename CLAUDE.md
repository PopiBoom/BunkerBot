# BunkerBot — памятка для Claude

Telegram-бот на aiogram 3 + Claude API. Владелец общается по-русски, с телефона.

## Как устроено
- `bot.py` — запуск, меню команд, фоновая задача стёб-бота.
- `games/bunker/` — игра «Бункер»: `game.py` (ход игры), `content.py` (карточки, катастрофы,
  карты действий), `render.py` (картинки через Pillow, шрифты в `assets/fonts`).
- `handlers/roast.py` — стёб-бот «Пиздюк»: память чата, досье, /roast, /week, подколы,
  реакции, защита «бати» (создатель — kapustka, первый ID в ADMIN_IDS), обещания, фото, клоун дня.
- `handlers/admin.py` — /admin (статистика, рассылка, частоты, расходы ИИ, импорт истории, /backup).
- `ai.py` — все запросы к Claude: AI_MODEL (Opus) для сценария/вердикта/прожарок,
  AI_MODEL_FAST (Haiku) для коротких реплик, AI_MODEL_EDIT (Sonnet) — редактор реплик.
- `database.py` — SQLite (`bot.db`).

## Где работает и как обновлять
- Бот живёт на VPS владельца: `/opt/bunkerbot`, служба `bunkerbot` (systemd).
- Сервер **сам** забирает код из ветки `main` GitHub раз в 2 минуты (`deploy/update.sh`).
  Значит: чтобы изменение попало на сервер — его надо **запушить/слить в `main`**.
- Доступа к серверу у Claude нет (SSH из облака закрыт). Логи владелец смотрит сам:
  `journalctl -u bunkerbot -f`.

## Правила
- Никогда не коммить `.env`, `bot.db`, бэкапы `*.db`, переписку и досье — репозиторий публичный.
- Перед пушем: `python -m py_compile` на изменённых файлах; для игры есть смысл прогнать
  партию с фейковым ботом (см. историю коммитов), для ИИ-фишек — проверить на реальном API.
- Красные линии стёба (не убирать): внешность, здоровье, семья, деньги, национальность,
  религия, ориентация, политика, угрозы. Бате бот не грубит.
