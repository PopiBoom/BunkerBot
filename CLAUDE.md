# BunkerBot — памятка для Claude

Telegram-бот на aiogram 3 + Claude API. Владелец общается по-русски, с телефона.

## Как устроено
- `bot.py` — запуск, меню команд, фоновая задача стёб-бота.
- `dashes.py` — владелец хочет «-», а не «—»: middleware сессии меняет длинное тире на дефис во ВСЁМ,
  что уходит в Telegram (текст, подписи, опросы, кнопки, алерты, меню); на картинках — `plain_dashes`
  в `_wrap`. В коде и промптах тире можно не вычищать.
- `games/bunker/` — игра «Бункер»: `game.py` (ход игры), `content.py` (карточки, катастрофы,
  карты действий, звания для /top), `render.py` (картинки через Pillow, шрифты в `assets/fonts`;
  в конце партии — титры с номинациями), `icons.py` (значки персонажей по «Данным»: человек,
  камень, инопланетянин… — рисуются примитивами, без ИИ).
- `games/mafia/` — «Мафия»: `game.py` (лобби, ночь в ЛС, утро, день, голосование, финал, /mafia_top),
  `content.py` (роли, раздача по числу игроков, тексты без ИИ, звания), `render.py` (карта роли, обложка,
  титры; значки ролей примитивами). Классика: мафия (+Дон с 6 игроков), Комиссар, Доктор, мирные.
  Решения владельца: роль убитого открывается сразу; ночью удаляются ВСЕ сообщения в чате (молча, без
  предупреждений); ночь — по очереди: Доктор → Комиссар → мафия (проверки Дона нет — убрал владелец), шаг кончается, как только
  все его роли выбрали, в чате только «Просыпается Доктор…» → «Доктор сделал выбор»; выбор мафии
  окончательный (поменять нельзя); мёртвые молчат; последнее слово — по желанию и без паузы: бот пишет убитому/казнённому
  в ЛС, тот присылает ОДНО сообщение — текст, голосовое или кружок до минуты, бот пересылает его в чат
  (`on_last_word`, голосовое/кружок — через `copy_message`); голосование ТАЙНОЕ, полосками
  как в Бункере; в финале — коротко «партия окончена, победила …» и сразу титры-картинка (роли — на ней);
  тайного чата мафии через бота нет (семья видит голоса друг друга в ЛС, при равенстве решает Дон).
  Финал: сначала «партия окончена» + эпилог одним сообщением, ПОТОМ картинка. Тексты — коротко и без
  лишних эмодзи (владелец просил); обо всех — в мужском роде («убит», не «убит(а)»), и в промптах ведущего тоже. Голосование закрывается сразу, как только проголосовали все живые.
  Правки сообщений чата — через `_chat_edit` под замком партии: иначе отложенная правка голосования
  с кнопками ложилась поверх закрытого (кнопки на всех игроков в переголосовании). В Бункере то же:
  `_refresh_vote`/`_refresh_threat` и закрытие голосований — под `game.edit_lock`. Мафия есть и в /stats.
  Комментарии к постам канала (ответ на пересланный пост или сообщение в его ветке) игры НЕ удаляют —
  `games.is_comment`; id постов запоминает middleware в bot.py и `load_channel_posts` при старте игры. Ведущий (ИИ, `ai.mafia_*`, Sonnet; эпилог — Opus)
  ролей не знает — видит только публичное (иначе выдаст мафию). Таймеры — константы в начале `game.py`,
  для тестов `TIME_SCALE = 0.004`.
- Лобби Бункера и Мафии — картинкой (`assets/lobby/*.jpg`, тоже `tools/static_images.py`) с подписью:
  список игроков меняется через `_edit_lobby` (`edit_message_caption`); подсказок «жми Вступить…» в тексте
  нет — владелец убрал.
- `games/__init__.py` — `active(chat_id)` (какая игра идёт, вместе с лобби; одна на чат), `hush()` (удалить
  сообщение из-за игры — нужно middleware для команд не-админов), `flag_loop()` — файл `.game_running`,
  пока идёт игра: `deploy/update.sh` не перезапускает бота, пока флаг свежий (< 2 мин).
- `handlers/roast.py` — стёб-бот «Пиздюк»: память чата, досье, /roast, /week, подколы,
  реакции, защита «бати» (создатель — kapustka, первый ID в ADMIN_IDS), обещания, фото, клоун дня,
  комментарии к постам канала бати (Memento Mori, `BOT_CHANNEL_NAMES`), стикеры и гифки чата
  (Haiku один раз описывает каждый по картинке/превью, описание хранится в `stickers.descr`).
  Каждое фото в чате Haiku коротко описывает в память («[фото: …]») — бот знает, что на нём, даже
  если не комментировал; комментарий к фото пишет Sonnet, редактор (Sonnet) тоже видит фото и ловит
  пересказ («чипсы, пирожки и кола — …») на любом пути, включая фоновые подколы.
  Пока идёт игра (Бункер или Мафия, `_bunker_active` → `games.active`), стёб-бот молчит; сообщения
  не-игроков игра удаляет (нужно право удалять).
  Пол участников — по их же фразам («я пошёл/пошла», таблица `user_gender`). Реакции на шутки бота
  (🔥/🤣 vs 👎/🤡) копятся в `bot_line_score`, удачные идут ИИ образцом. Кружки и видео — кадр из
  середины (`frames.py`, PyAV), без него — превью Telegram. После /forget_me (его делает админ): без реакций и рифм.
  Ответы «как человек»: «печатает» по длине, иногда двумя сообщениями (`_say_human`).
- `handlers/fun.py` — /poll «Кто из нас…» (ИИ-вопрос, варианты — активные участники, итоги через 15 мин с
  прожаркой) и «вопрос дня» в тишину (3 ч днём, раз в сутки; вкл/выкл в /admin). Фон — из roast.background.
- `handlers/channel_posts.py` — посты бота «от себя» в канал бати (сейчас только тест: каждые 2 мин,
  сам выключается через 30 мин; /admin → «📢 Посты в канал»). Канал — linked_chat_id чата или
  BOT_CHANNEL_ID. Пишет AI_MODEL_POSTS — по умолчанию по очереди Opus 5.5 и Gemini 4 Argon (победители
  слепого /compare владельца; Gemini — через OpenRouter, без ключа только Opus), effort high —
  на Sonnet/low юмор был плоский. Без подписи; тон злой, с матом и оскорблениями «вас»/людей в целом — без имён и
  переписки из чата (канал публичный); свои посты в чате не комментирует.
- `handlers/compare.py` — /compare (админ, ЛС): слепое сравнение моделей на постах (ai.COMPARE_MODELS:
  Claude напрямую, остальные — OpenRouter, `OPENROUTER_API_KEY`); победитель → настройка `post_model`
  в базе (перекрывает AI_MODEL_POSTS). `ai.complete_any()`: модель с «/» — OpenRouter, иначе Claude SDK.
  Ключ OpenRouter: `.env` или `/setkey` в ЛС боту (хранится в базе, настройка `openrouter_key`;
  в репозиторий ключи не класть — он публичный).
- `handlers/menu.py` — /menu: картинка с разделами и кнопки; раздел — та же сообщение, другая картинка
  (`edit_media`) и кнопки действий; действие = вызов обработчика команды от имени нажавшего (`run_action`,
  копия сообщения с from_user). Разделы листать может любой, действия — только админ. Картинки — готовые
  `assets/menu/*.jpg`, рисует их `tools/static_images.py` из `SECTIONS` (нужен шрифт Noto Color Emoji —
  есть в облачной сессии, на сервере не нужен). Поменял разделы — перерисуй и закоммить картинки.
- `handlers/quotes.py` — цитатник «золотой фонд» (/quote, картинка-карточка, фразы дня от ИИ).
- `handlers/stats.py` — /stats: статистика чата и личная, без ИИ (мат, нытьё, совы, молчуны).
- `commands.py` — все команды по разделам: из него строятся меню «/» и /help (`handlers/help.py`).
  Новую команду добавлять туда, иначе её не будет в меню.
  Команды в группе бот сразу удаляет (до выполнения; ответы уходят без «ответа на», `allow_sending_without_reply=True`)
  — «@имя_бота» после команды дописывает сам Telegram, владельцу не нравится. Меню «/» — полное (короткое владелец не захотел), в чате — с
  строками-разделителями разделов (`commands.SEPARATORS`: «/mafia_ ━━ 🕵️ МАФИЯ ━━» — пустые команды, нажатие бот просто удаляет).
  **Команды — только админам** (middleware `AdminOnlyCommands` в bot.py), кроме `PUBLIC_COMMANDS` = /start
  (подписка и вход в Бункер). Чужие команды бот молча игнорирует; у участников меню «/» пустое (в личке — /start).
  /forget_me и /remember_me — тоже только админ, но к любому: ответом на сообщение или @ником
  (у «забытых» в roast_optout хранится имя и @ник — чтобы вернуть).
- `handlers/admin.py` — /admin (статистика, рассылка, частоты, расходы ИИ, импорт истории, /backup,
  ночной автобэкап базы первому админу в ЛС — ~05:00 МСК, вкл/выкл в /admin).
- `ai.py` — все запросы к Claude: AI_MODEL (Opus) для сценария/вердикта/прожарок,
  AI_MODEL_REPLY (по умолчанию = Sonnet) пишет ответы людям в чате, AI_MODEL_EDIT (Sonnet) — редактор,
  AI_MODEL_FAST (Haiku) — только служебное: описать фото/стикер, реакция, обещание, досье.
  Перед отправкой: `scrub()` вырезает слова за красными линиями, `about_looks()` — шутки про внешность.
- `rhymes.py` — рифмы-отговорки без ИИ («и чё?» — «хуй через плечо», «ну» — «баранки гну»): ответ боту —
  почти всегда, в общем чате — изредка, раз в 15 мин; бате — только в «грубый» раз.
- `links.py` — что за ссылка (YouTube/TikTok oEmbed, og:title); защита от адресов внутренней сети.
- `database.py` — SQLite (`bot.db`).

## Где работает и как обновлять
- Бот живёт на VPS владельца: `/opt/bunkerbot`, служба `bunkerbot` (systemd).
- Сервер **сам** забирает код из ветки `main` GitHub раз в 2 минуты (`deploy/update.sh`).
  Значит: чтобы изменение попало на сервер — его надо **запушить/слить в `main`**.
- Доступа к серверу у Claude нет (SSH из облака закрыт). Логи владелец смотрит сам:
  `journalctl -u bunkerbot -f`.

## Правила
- Никогда не коммить `.env`, `bot.db`, бэкапы `*.db`, переписку и досье — репозиторий публичный.
- Перед пушем: `python -m py_compile` на изменённых файлах; для игры есть смысл прогнать
  партию с фейковым ботом (см. историю коммитов), для ИИ-фишек — проверить на реальном API.
- Красные линии стёба (не убирать): внешность, здоровье, семья, деньги, национальность,
  религия, ориентация, политика, угрозы. Бате бот иногда (≈1 из 3, `FATHER_RUDE_CHANCE`) грубит
  по-сыновьи с матом — так хочет владелец; от наездов других заступается.

## Как работать с владельцем (договорённости)
- Пишет с телефона, по-русски. Отвечать коротко и по делу: что сделано, как проверить, сколько стоит.
- **Всё сразу в `main`** — без веток и PR (сервер тянет `main`). После пуша — номер коммита и как
  проверить на сервере (`journalctl -u bunkerbot-update -n 3` → «Обновлён: … -> <коммит>»).
- Ключи в чат просить нельзя. Если владелец сам прислал ключ — использовать только в командах сессии,
  в файлы/репозиторий не писать, напомнить перевыпустить. Ключ OpenRouter на сервер — через `/setkey`
  боту в ЛС. Для проверок на реальном API в облачной сессии ключ лучше добавить в настройки окружения.
- Решения владельца, которые не переигрывать без его просьбы:
  - словарь ругательств (`ai.INSULTS`) — только жёсткие; красные линии всё равно держим в коде;
  - бате бот иногда грубит (≈1 из 3), «бать» — изредка, без передразнивания;
  - все команды — только админу; /forget_me и /remember_me админ делает за других;
  - посты в канал пишут Opus 5.5 + Gemini 4 Argon по очереди (победили в его слепом сравнении);
  - скачивание музыки — **отказались** (пиратство); варианты «отрывок 30 сек + ссылки» ему не нужны.
- Отказано и не делать: ключи в публичный репозиторий; оскорбления по инвалидности, национальности,
  ориентации, религии, внешности; полные треки с YouTube.

## Как проверять изменения (в облачной сессии)
- `python -m py_compile` и `python -m pyflakes` на всё; ruff с `--select E9,F,B,PLE,ASYNC` — чисто.
- Мафия: `games.mafia.game.TIME_SCALE = 0.004`, `REFRESH_DELAY = 0.01`; заглушка бота с `send_message/send_photo/
  edit_message_text`, лобби через `cmd_mafia` + `cmd_mafia_bots` + `cb_start`; «живой» игрок жмёт кнопки,
  вызывая `cb_kill/cb_sheriff_check/cb_heal/cb_vote` с утиным CallbackQuery (ночные кнопки
  приходят только в шаг своей роли: `game.night_step`); ждать, пока чат
  не пропадёт из `G.games`.
- Бункер: партия с тестовыми ботами без ИИ — подменить `asyncio.sleep`, таймауты в `games.bunker.game`
  (`TURN_TIMEOUT`, `SPEECH_AT`, `THREAT_VOTE`, `HOST_DELAY`…) уменьшить, `Bot` — заглушка с `__getattr__`,
  игроки `Player(is_bot=True)`, `await G._run_game(FakeBot(), game)`; плюс один «живой» игрок для записи
  статистики в настоящую `Database`.
- Стёб-бот: обработчики вызываются напрямую с `aiogram.types.Message(...)` и заглушкой бота
  (`send_message`, `download`, `set_message_reaction`…); для ИИ-фишек — реальный API с ключом.
- Типовые проблемы ответов, уже закрытые кодом (если вернутся — чинить там же, а не только промптом):
  пересказ фото → `retells/drop_retell` в `polish`; эхо «любит он, ага» → `drop_echo`; короткий ответ
  «Я» → `short_answer_meaning`; смех на шутку → `_maybe_laugh`; пустые реплики — не цель фоновых
  подколов (`_trivial`); внешность → `about_looks/fix_looks`; запретные слова → `scrub` в `_say`;
  «бать» в каждом ответе → `vary_father`; обрезанные надписи на фото — правило в `describe_photo`.
- Модели и цены ($ за 1M вход/выход): Opus 5.5 4/20, Fable 5.1 10/50, Sonnet 5.5 2/10, Haiku 5.5 0.1/0.5;
  через OpenRouter: Gemini 4 Argon ~2/10 (на деле ≈$0.003 за пост), GPT-6.1 Terra Pro 1/5, Grok 4.7 2/6.
  Во всех запросах по умолчанию `effort=low` (`ai._complete`), посты — `high` (иначе юмор плоский).
