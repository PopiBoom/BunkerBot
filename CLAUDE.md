# BunkerBot — памятка для Claude

Telegram-бот на aiogram 3 + Claude API. Владелец общается по-русски, с телефона.

## Как устроено
- `bot.py` — запуск, меню команд, фоновая задача стёб-бота.
- `games/bunker/` — игра «Бункер»: `game.py` (ход игры), `content.py` (карточки, катастрофы,
  карты действий, звания для /top), `render.py` (картинки через Pillow, шрифты в `assets/fonts`;
  в конце партии — титры с номинациями), `icons.py` (значки персонажей по «Данным»: человек,
  камень, инопланетянин… — рисуются примитивами, без ИИ).
- `handlers/roast.py` — стёб-бот «Пиздюк»: память чата, досье, /roast, /week, подколы,
  реакции, защита «бати» (создатель — kapustka, первый ID в ADMIN_IDS), обещания, фото, клоун дня,
  комментарии к постам канала бати (Memento Mori, `BOT_CHANNEL_NAMES`), стикеры и гифки чата
  (Haiku один раз описывает каждый по картинке/превью, описание хранится в `stickers.descr`).
  Каждое фото в чате Haiku коротко описывает в память («[фото: …]») — бот знает, что на нём, даже
  если не комментировал; комментарий к фото пишет Sonnet, редактор (Sonnet) тоже видит фото и ловит
  пересказ («чипсы, пирожки и кола — …») на любом пути, включая фоновые подколы.
  Пока идёт «Бункер», стёб-бот молчит; сообщения не-игроков игра удаляет (нужно право удалять).
  Пол участников — по их же фразам («я пошёл/пошла», таблица `user_gender`). Реакции на шутки бота
  (🔥/🤣 vs 👎/🤡) копятся в `bot_line_score`, удачные идут ИИ образцом. Кружки и видео — кадр из
  середины (`frames.py`, PyAV), без него — превью Telegram. После /forget_me (его делает админ): без реакций и рифм.
  Ответы «как человек»: «печатает» по длине, иногда двумя сообщениями (`_say_human`).
- `handlers/fun.py` — /poll «Кто из нас…» (ИИ-вопрос, варианты — активные участники, итоги через 15 мин с
  прожаркой) и «вопрос дня» в тишину (3 ч днём, раз в сутки; вкл/выкл в /admin). Фон — из roast.background.
- `handlers/channel_posts.py` — посты бота «от себя» в канал бати (сейчас только тест: каждые 2 мин,
  сам выключается через 30 мин; /admin → «📢 Посты в канал»). Канал — linked_chat_id чата или
  BOT_CHANNEL_ID. Пишет AI_MODEL_POSTS — по умолчанию по очереди Opus 5.5 и Gemini 4 Argon (победители
  слепого /compare владельца; Gemini — через OpenRouter, без ключа только Opus), effort high —
  на Sonnet/low юмор был плоский. Без подписи; тон злой, с матом и оскорблениями «вас»/людей в целом — без имён и
  переписки из чата (канал публичный); свои посты в чате не комментирует.
- `handlers/compare.py` — /compare (админ, ЛС): слепое сравнение моделей на постах (ai.COMPARE_MODELS:
  Claude напрямую, остальные — OpenRouter, `OPENROUTER_API_KEY`); победитель → настройка `post_model`
  в базе (перекрывает AI_MODEL_POSTS). `ai.complete_any()`: модель с «/» — OpenRouter, иначе Claude SDK.
  Ключ OpenRouter: `.env` или `/setkey` в ЛС боту (хранится в базе, настройка `openrouter_key`;
  в репозиторий ключи не класть — он публичный).
- `handlers/quotes.py` — цитатник «золотой фонд» (/quote, картинка-карточка, фразы дня от ИИ).
- `handlers/stats.py` — /stats: статистика чата и личная, без ИИ (мат, нытьё, совы, молчуны).
- `commands.py` — все команды по разделам: из него строятся меню «/» и /help (`handlers/help.py`).
  Новую команду добавлять туда, иначе её не будет в меню.
  **Команды — только админам** (middleware `AdminOnlyCommands` в bot.py), кроме `PUBLIC_COMMANDS` = /start
  (подписка и вход в Бункер). Чужие команды бот молча игнорирует; у участников меню «/» пустое (в личке — /start).
  /forget_me и /remember_me — тоже только админ, но к любому: ответом на сообщение или @ником
  (у «забытых» в roast_optout хранится имя и @ник — чтобы вернуть).
- `handlers/admin.py` — /admin (статистика, рассылка, частоты, расходы ИИ, импорт истории, /backup,
  ночной автобэкап базы первому админу в ЛС — ~05:00 МСК, вкл/выкл в /admin).
- `ai.py` — все запросы к Claude: AI_MODEL (Opus) для сценария/вердикта/прожарок,
  AI_MODEL_REPLY (по умолчанию = Sonnet) пишет ответы людям в чате, AI_MODEL_EDIT (Sonnet) — редактор,
  AI_MODEL_FAST (Haiku) — только служебное: описать фото/стикер, реакция, обещание, досье.
  Перед отправкой: `scrub()` вырезает слова за красными линиями, `about_looks()` — шутки про внешность.
- `rhymes.py` — рифмы-отговорки без ИИ («и чё?» — «хуй через плечо», «ну» — «баранки гну»): ответ боту —
  почти всегда, в общем чате — изредка, раз в 15 мин; бате — только в «грубый» раз.
- `links.py` — что за ссылка (YouTube/TikTok oEmbed, og:title); защита от адресов внутренней сети.
- `database.py` — SQLite (`bot.db`).

## Где работает и как обновлять
- Бот живёт на VPS владельца: `/opt/bunkerbot`, служба `bunkerbot` (systemd).
- Сервер **сам** забирает код из ветки `main` GitHub раз в 2 минуты (`deploy/update.sh`).
  Значит: чтобы изменение попало на сервер — его надо **запушить/слить в `main`**.
- Доступа к серверу у Claude нет (SSH из облака закрыт). Логи владелец смотрит сам:
  `journalctl -u bunkerbot -f`.

## Правила
- Никогда не коммить `.env`, `bot.db`, бэкапы `*.db`, переписку и досье — репозиторий публичный.
- Перед пушем: `python -m py_compile` на изменённых файлах; для игры есть смысл прогнать
  партию с фейковым ботом (см. историю коммитов), для ИИ-фишек — проверить на реальном API.
- Красные линии стёба (не убирать): внешность, здоровье, семья, деньги, национальность,
  религия, ориентация, политика, угрозы. Бате бот иногда (≈1 из 3, `FATHER_RUDE_CHANCE`) грубит
  по-сыновьи с матом — так хочет владелец; от наездов других заступается.
