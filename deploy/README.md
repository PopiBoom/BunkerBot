# Переезд BunkerBot на свой сервер (VPS)

Всё делается с телефона. Займёт 15–20 минут.

## 1. Купить сервер

Подойдёт самый дешёвый VPS (1 ядро, 1 ГБ памяти, 10+ ГБ диска), ~200–500 ₽/мес.
**Система: Ubuntu 24.04 или 22.04.** После покупки хостинг пришлёт:
**IP-адрес**, логин (обычно `root`) и **пароль**.

## 2. Подключиться к серверу с телефона

Поставь приложение **Termius** (Android / iPhone) → «New host» → впиши IP, логин `root`
и пароль → Connect. Откроется чёрный экран с командной строкой — это и есть сервер.

## 3. Сделать бэкап на старом месте

Напиши боту в личку `/backup` (или `/admin` → «💾 Бэкап базы»). Бот пришлёт файл
`bunkerbot-backup-….db` — в нём досье, переписка, рейтинги, обещания, настройки.

> ⚠️ Один и тот же бот не может работать в двух местах сразу. Как только сделал бэкап —
> останови старый бот (в чате с Claude: «останови бота»), и только потом запускай новый.

## 4. Установить бота одной командой

Вставь в Termius и нажми Enter:

```bash
curl -fsSL https://raw.githubusercontent.com/PopiBoom/BunkerBot/main/deploy/install.sh | bash
```

Скрипт поставит всё нужное и спросит 4 значения — вставь их по очереди:

| Что спросит | Где взять |
|---|---|
| `BOT_TOKEN` | у @BotFather (лучше выпустить новый: `/revoke`) |
| `ADMIN_IDS` | твой Telegram ID |
| `REQUIRED_CHATS` | `@memento_mori_osn -1001956746199` |
| `ANTHROPIC_API_KEY` | console.anthropic.com → API Keys (лучше новый) |

В конце будет «✅ Готово!» — бот уже работает.

## 5. Вернуть досье и всё остальное

Перешли боту в личку файл бэкапа из шага 3. Он ответит «✅ База восстановлена».

## Как дальше менять бота

Просто пиши Claude, что поменять. Он правит код и отправляет в GitHub, а сервер **сам**
забирает обновления раз в 2 минуты и перезапускает бота. На сервер заходить не нужно.

## Полезные команды (в Termius)

| Что | Команда |
|---|---|
| Работает ли бот | `systemctl status bunkerbot` |
| Логи вживую | `journalctl -u bunkerbot -f` |
| Перезапустить | `systemctl restart bunkerbot` |
| Поменять токены | `nano /opt/bunkerbot/.env`, потом перезапуск |
| Обновить прямо сейчас | `systemctl start bunkerbot-update` |
