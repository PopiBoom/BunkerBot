# BunkerBot

Телеграм-бот для твоего канала/чата: игра **«Бункер»** с ведущим на базе Claude
плюс шлюз подписки (выдаёт контент после подписки на канал).

## Возможности

### 🏚 Игра «Бункер» (в групповом чате)
- `/bunker` — лобби. Вход только через ЛС бота (кнопка «Вступить в игру»).
  Ведущий выбирает режим ИИ-ведущего: 🎙 Классика, 😈 Злой, 🤗 Ласковый, 🤡 Кринж
  (или сразу `/bunker злой`).
- ИИ генерирует катастрофу, бункер, 8 фактов о бункере и карточки из 9 характеристик,
  включая «💞 Связь» с другим игроком (встречались, должен денег, соседи…).
- В ЛС каждому приходит **карточка-картинка** («пропуск в бункер») и одноразовая
  **карта действия**.
- В чате закрепляется **табло**: раунд, места, известное о бункере, открытые карты.
- Раунд: новый факт о бункере → игроки по очереди открывают характеристику
  (таймер прямо в сообщении) → одна реплика ведущего на раунд. В маленьких партиях
  первые раунды — разогрев без голосования (до 4 игроков — 2, до 8 — 1).
- Голосование: полоски голосов, голосуют только игроки. **Последнее слово** — только
  если у лидеров поровну голосов (30 сек, остальные могут поменять голос); ничья осталась —
  переголосование только между ними (до 2 раз, потом жребий). Ведущий оценивает речи,
  но не решает, кто вылетает.
- **Угроза** в середине партии (от 4 игроков): ЧП в бункере, 90 сек на голосование,
  кого отправить. Шанс погибнуть ИИ считает по карточке и держит в тайне.
  Погиб — обычного голосования в этом раунде нет; выжил — иммунитет на ближайшее.
- Во время партии стёб-бот молчит, а сообщения тех, кто не играет, удаляются.
- Выбывший получает досье-картинку с печатью «ОТКАЗАНО» (или «ПОГИБ»).
- Обложка партии: картинка с названием и описанием катастрофы.
- На карточке — значок персонажа по «Данным» (человек, камень, инопланетянин, кактус…);
  примерно треть персонажей — не люди.
- Финал: анимация «люк задраен», альбом пропусков выживших, эпилог и **вердикт —
  выжила ли колония**, **титры** с номинациями (Мишень, Везунчик, Снайпер, Предатель, Герой).
- `/top` — рейтинг со **званиями** (👑 Король бункера, 🪳 Таракан, 💥 Камикадзе…);
  `/top` ответом или `/top @ник` — профиль игрока. `/bunker_stop` — остановить игру (ведущий).

**Карты действий:** ✌️ Двойной голос, 🧿 Проклятие (во время голосования);
🛡 Иммунитет (в любой момент — защищает в **следующем** голосовании), 🎭 Сорвать маску,
🔁 Обмен багажом, 🎲 Новая жизнь (в любой момент раунда).

### 🔥 Стёб-бот (в групповом чате)
- Запоминает текстовые сообщения (последние 3000 на чат) и ведёт досье на каждого:
  обещания, противоречия, хвастовство, коронные фразы.
- `/roast` — ответом на сообщение или `/roast @ник` — прожарка по досье.
- `/week` — итоги недели с номинациями; сам публикует их по воскресеньям после 20:00 МСК.
- Иногда сам подкалывает (частота — в `/admin`: от 10 сек до 6 часов или выкл;
  не во время «Бункера»). Отвечает, когда к нему обращаются; если посылают — посылает в ответ.
- **Ловушка на обещания:** замечает «с понедельника бросаю», «завтра в зал» и т.п., запоминает
  срок и в срок сам спрашивает, выполнил ли. `/promises` — что бот сейчас отслеживает.
- **Стёб по фото:** иногда (или когда фото адресовано боту) комментирует присланные картинки.
  Про внешность людей на фото не шутит.
- **Клоун дня:** каждый вечер после 21:00 МСК выбирает самого клоунского участника по сообщениям
  за день. `/clowns` — таблица позора.
- **Видит картинки:** каждое фото, кружок и видео (кадр из середины) коротко описывает в память;
  иногда комментирует — без пересказа «что на фото», сразу шуткой.
- **Стикеры и гифки:** запоминает, что кидают в чате (каждый один раз описывает по картинке),
  и сам кидает к месту. **Ссылки:** понимает, что за видео/страница (YouTube, TikTok, сайты).
- **Канал бати:** комментирует посты привязанного канала (`BOT_CHANNEL_NAMES`), понимает репосты.
- **Рифмы:** «и чё?» — «хуй через плечо», «ну» — «баранки гну» и ещё два десятка.
- Знает пол участников по их же фразам, учится на реакциях (🔥/🤣 — зашло, 👎/🤡 — нет),
  отвечает «как человек»: печатает по длине, иногда двумя сообщениями.
- `/poll` — опрос «Кто из нас…» по участникам чата (вопрос придумывает ИИ, через 15 минут — итоги
  и прожарка победителя). Если в чате долго тихо, бот сам подкидывает вопрос дня или опрос.
- `/quote` — цитатник «золотой фонд» (ответом — сохранить, просто так — случайная цитата
  картинкой; лучшие фразы дня бот добавляет сам). `/stats` — статистика чата и личная.
- Защищает «батю» (создателя) от наездов; самому бате иногда грубит по-сыновьи.
- `/forget_me` — удалить всё о себе и не попадать под стёб, `/remember_me` — вернуться.
- Запрещённые темы: внешность, здоровье, семья, деньги, национальность, религия,
  ориентация, политика — такие слова и шутки вырезаются в коде перед отправкой.
  Включается и выключается в `/admin`.

### ✅ Шлюз подписки
- `/start` в личке — проверяет подписку на канал/чат (`get_chat_member`) и после
  подтверждения выдаёт контент (ссылку на чат и т.п.).
- `/admin` — статистика, рассылка, редактирование текстов, 💰 расходы на ИИ, частоты стёба,
  импорт истории, бэкап (и ночной автобэкап в личку). `/help` — все команды по разделам.

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env   # затем заполни .env
python bot.py
```

### Переменные `.env`

| Переменная         | Назначение                                                        |
|--------------------|-------------------------------------------------------------------|
| `BOT_TOKEN`        | токен от @BotFather                                               |
| `ADMIN_IDS`        | Telegram ID админов (через пробел)                                |
| `REQUIRED_CHATS`   | `@username` или id канала/чата для проверки подписки              |
| `ANTHROPIC_API_KEY`| ключ Claude API для ведущего игры                                |
| `AI_MODEL`         | модель для сценария, шансов угрозы и вердикта (по умолчанию claude-opus-5-5) |
| `AI_MODEL_FAST`    | служебная модель: короткие реплики ведущего, описания фото/стикеров (claude-haiku-5-5) |
| `AI_MODEL_EDIT`    | редактор реплик стёб-бота (claude-sonnet-5-5)                      |
| `AI_MODEL_REPLY`   | кто пишет ответы людям в чате (по умолчанию = `AI_MODEL_EDIT`)     |
| `BOT_CHANNEL_NAMES`| названия каналов бати, посты которых бот комментирует (Memento Mori) |
| `BOT_FATHER_NAME` / `BOT_FATHER_ID` | имя и ID «бати» (по умолчанию kapustka и первый из `ADMIN_IDS`) |
| `BUNKER_DELAY`     | пауза между сюжетными сообщениями игры в секундах (по умолчанию 20) |
| `DB_PATH`          | путь к базе (по умолчанию bot.db)                                 |
| `BOT_PROXY`        | HTTP/SOCKS-прокси для Telegram (нужен лишь в закрытых сетях)      |

## Важно

- Бот должен быть **администратором** в канале и чате.
- Для игры каждый игрок открывает бота в ЛС — кнопка «Вступить в игру» делает это автоматически.
- `ANTHROPIC_API_KEY` платный. Без ключа игра работает на встроенном генераторе.

## Структура

```
bot.py            # запуск, подключение роутеров
config.py         # чтение .env
database.py       # SQLite: пользователи, настройки, память чата, досье, цитаты, статистика
subscription.py   # проверка подписки + ссылки
keyboards.py      # клавиатуры
texts.py          # тексты по умолчанию
commands.py       # все команды по разделам — меню «/» и /help
ai.py             # все запросы к Claude: ведущий игры, стёб, редактор, описания картинок
links.py          # что за ссылка (YouTube/TikTok/сайт), с защитой от внутренних адресов
frames.py         # кадр из середины видео/кружка (PyAV)
rhymes.py         # рифмы-отговорки («и чё?» — «хуй через плечо»)
handlers/         # user.py (подписка), admin.py (админка), roast.py (стёб-бот),
                  # quotes.py (/quote), stats.py (/stats), fun.py (/poll, вопрос дня), help.py (/help)
games/bunker/     # game.py (ход игры), content.py (карты, режимы, звания),
                  # render.py (картинки, титры), icons.py (значки персонажей)
assets/fonts/     # шрифты DejaVu для карточек
```
