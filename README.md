# BunkerBot

Телеграм-бот для твоего канала/чата: игра **«Бункер»** с ведущим на базе Claude
плюс шлюз подписки (выдаёт контент после подписки на канал).

## Возможности

### 🏚 Игра «Бункер» (в групповом чате)
- `/bunker` — лобби. Вход только через ЛС бота (кнопка «Вступить в игру»).
  Ведущий выбирает режим ИИ-ведущего: 🎙 Классика, 😈 Злой, 🤗 Ласковый, 🤡 Кринж
  (или сразу `/bunker злой`).
- ИИ генерирует катастрофу, бункер, 8 фактов о бункере и карточки из 9 характеристик,
  включая «💞 Связь» с другим игроком (встречались, должен денег, соседи…).
- В ЛС каждому приходит **карточка-картинка** («пропуск в бункер») и одноразовая
  **карта действия**.
- В чате закрепляется **табло**: раунд, места, известное о бункере, открытые карты.
- Раунд: новый факт о бункере → игроки по очереди открывают характеристику
  (таймер прямо в сообщении) → одна реплика ведущего на раунд.
- Голосование: полоски голосов, голосуют только игроки. На 45-й секунде двое лидеров
  получают **последнее слово** (30 сек), после речей — сразу итог. Ничья —
  переголосование только между равными (до 2 раз, потом жребий).
- **Угроза** в середине партии (от 4 игроков): ЧП в бункере, 45 сек на голосование,
  кого отправить. У каждого виден шанс погибнуть — ИИ считает его по открытым картам.
  Погиб — обычного голосования в этом раунде нет; выжил — иммунитет на ближайшее.
- Выбывший получает досье-картинку с печатью «ОТКАЗАНО» (или «ПОГИБ»).
- Обложка партии: картинка с названием и описанием катастрофы.
- Финал: анимация «люк задраен», альбом пропусков выживших, эпилог и **вердикт —
  выжила ли колония**, итоговая открытка для канала.
- `/top` — рейтинг выживших, `/bunker_stop` — остановить игру (только ведущий).

**Карты действий:** 🛡 Иммунитет, ✌️ Двойной голос, 🧿 Проклятие (во время
голосования); 🎭 Сорвать маску, 🔁 Обмен багажом, 🎲 Новая жизнь (в любой момент раунда).

### 🔥 Стёб-бот (в групповом чате)
- Запоминает текстовые сообщения (30 дней) и ведёт короткое досье на каждого:
  обещания, противоречия, хвастовство, коронные фразы.
- `/roast` — ответом на сообщение или `/roast @ник` — прожарка по досье.
- `/week` — итоги недели с номинациями; сам публикует их по воскресеньям после 20:00 МСК.
- Иногда сам подкалывает (частота — в `/admin`: от 10 сек до 6 часов или выкл;
  не во время «Бункера»). Отвечает, когда к нему обращаются; если посылают — посылает в ответ.
- `/forget_me` — удалить всё о себе и не попадать под стёб, `/remember_me` — вернуться.
- Запрещённые темы: внешность, здоровье, семья, деньги, национальность, религия,
  ориентация, политика. Включается и выключается в `/admin`.

### ✅ Шлюз подписки
- `/start` в личке — проверяет подписку на канал/чат (`get_chat_member`) и после
  подтверждения выдаёт контент (ссылку на чат и т.п.).
- `/admin` — статистика, рассылка, редактирование текстов, 💰 расходы на ИИ.

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env   # затем заполни .env
python bot.py
```

### Переменные `.env`

| Переменная         | Назначение                                                        |
|--------------------|-------------------------------------------------------------------|
| `BOT_TOKEN`        | токен от @BotFather                                               |
| `ADMIN_IDS`        | Telegram ID админов (через пробел)                                |
| `REQUIRED_CHATS`   | `@username` или id канала/чата для проверки подписки              |
| `ANTHROPIC_API_KEY`| ключ Claude API для ведущего игры                                |
| `AI_MODEL`         | модель для сценария, шансов угрозы и вердикта (по умолчанию claude-opus-5-5) |
| `AI_MODEL_FAST`    | модель для коротких реплик ведущего (по умолчанию claude-haiku-5-5) |
| `BUNKER_DELAY`     | пауза между сообщениями игры в секундах (по умолчанию 5)          |
| `DB_PATH`          | путь к базе (по умолчанию bot.db)                                 |
| `BOT_PROXY`        | HTTP/SOCKS-прокси для Telegram (нужен лишь в закрытых сетях)      |

## Важно

- Бот должен быть **администратором** в канале и чате.
- Для игры каждый игрок открывает бота в ЛС — кнопка «Вступить в игру» делает это автоматически.
- `ANTHROPIC_API_KEY` платный. Без ключа игра работает на встроенном генераторе.

## Структура

```
bot.py            # запуск, подключение роутеров
config.py         # чтение .env
database.py       # SQLite: пользователи и настройки
subscription.py   # проверка подписки + ссылки
keyboards.py      # клавиатуры шлюза подписки
texts.py          # тексты по умолчанию
ai.py             # ведущий игры на Claude (сценарий, карточки, шутки)
handlers/         # user.py (подписка), admin.py (админка), roast.py (стёб-бот)
games/bunker/     # game.py (ход игры), content.py (карты, цели, режимы), render.py (картинки)
assets/fonts/     # шрифты DejaVu для карточек
```
